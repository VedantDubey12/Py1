# Python Programs Collection

Core Python programs in one file, `programs.py`.

## Programs

| Program | What it does |
|---|---|
| `factorial(n)` | Factorial using a loop |
| `factorial_recursive(n)` | Factorial using recursion |
| `fibonacci(count)` | First `count` numbers of the Fibonacci series |
| `pairs_to_dict(pairs)` | List of (key, value) pairs to a dictionary |
| `lists_to_dict(keys, values)` | Two lists to a dictionary |
| `object_to_dict(obj)` | An object's attributes to a dictionary |

## How to run

```bash
python programs.py
```
